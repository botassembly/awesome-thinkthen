# Awesome ThinkThen

Models, servers, benchmarks, talks, and articles that work with [ThinkThen](https://github.com/botassembly/thinkthen). ThinkThen turns a decision model's three endpoints into ten typed functions for the shell, libraries, and databases.

A backend joins this list after the ThinkThen compliance check passes against it. Each entry names the check's result and the date it ran.

## ThinkThen

- [ThinkThen](https://github.com/botassembly/thinkthen): the command, the libraries, and the database extensions.

## Hosted backends
