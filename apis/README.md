# APIs

The decision APIs this list supports, one file each. An entry's check result says which of these it speaks.

- [System One](system1.md): TypeSafe's decision API, the shape Jev, Liquid d1, Kev, and Ollama's decision models speak. Supported today.
- [Decisions API](decisions-api.md): OpenAI's decision API, in public beta. ThinkThen 0.2 speaks it through the `openai` backend.
