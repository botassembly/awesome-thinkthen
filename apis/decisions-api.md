# Decisions API

OpenAI's decision API. Waiting on OpenAI's documentation.

What is known, from the DevDay announcement of 2026-09-29: it is powered by Luna, it answers developer-defined questions with a finite set of predefined answers, the state can be text or images, and it opened in a limited preview. No endpoint, no schema, and no pricing are published yet.

When the documentation lands, this file gains the same sections [System One](system1.md) carries: the shape, the criteria rules per the published schema, the dialects observed, and the check results for every backend that speaks it.
