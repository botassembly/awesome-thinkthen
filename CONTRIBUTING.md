# Contributing

Open an issue. Pull requests are not accepted.

To propose a backend, server, benchmark, or article, [open an issue](https://github.com/botassembly/awesome-thinkthen/issues) with:

1. The project name and its address.
2. How it speaks System One (or which decision API it speaks instead).
3. For a backend or server: the output of `thinkthen check --url YOUR_BASE_URL --model YOUR_MODEL`, pasted whole, with the date it ran.

A maintainer runs the check again, scores the system on Beatles Bench, and adds the entry with its check result, its date, and a report page. An entry without a check is not listed as working.
